# 维护执行

用户请求维护时运行；“定期维护”是模式名称，不代表已有定时任务。安排自动运行必须另有明确授权和真实调度验收。

1. 按用户主题/时间/目录确定范围；未指定时检查索引和可检索的页面元数据，输出实际覆盖范围。
2. 检查缺来源/断链、孤立页、重复归档、未完成整合、冲突与过时风险。孤立不等于无价值；日期较旧不等于事实已失效。
3. 有现成证据且可确定的链接/索引问题可直接修复并保留副本。内容冲突需回查对应来源；无法判定时并列保留并记录待核验，不通过删除一方“解决”。
4. 重复原文仅标记关联，不自动删除；不为了完整性自行开启无限外部研究。用户要求仅检查时输出报告，不修改。
5. 读回修复结果并核验链接；记录已修复、未解决及证据，实际写入时追加日志。用小表格交付，不把局部抽查宣称全库验收。
